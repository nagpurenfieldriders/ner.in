GOOGLE SHEET SETUP / UPDATE  (account: nagpurenfieldrider@gmail.com)
Your Web app URL is already in js/main.js (SHEET_URL). Do NOT change it. Only update the script code:

1. Open your sheet -> Extensions > Apps Script.
2. Replace ALL the old code with the new google-sheet/Code.gs. Click Save.
3. Choose function "setup" and click Run (approve the permission if asked).
   It writes the new headings and adds Yes/No dropdowns in the tabs below. Your old rows are kept.
4. Deploy > Manage deployments > pencil (Edit) > Version: "New version" > Deploy.  (Skipping this = old code keeps running.)
5. Test in a browser:  <Web app URL>?a=debug   and   <Web app URL>?a=riders   and   <Web app URL>?a=rides
6. Clear the old TEST rows from Riders and Ride Registrations (the columns changed: UTR / screenshot columns are gone).

TABS AND COLUMNS
Riders              : Timestamp, Name, WhatsApp, Email, Date of birth, Profession, Bike model, Bike number, Membership, Fee, Registration type, Payment received, Show on website
Ride Registrations  : Timestamp, Ride, Date, Route, Rider name, WhatsApp, Bike model, Bike number, Riders (with pillion), Note, Total fee, Payment received
Merchandise Orders  : Timestamp, Item, Quantity, Size, Rider name, WhatsApp, Note
Upcoming Rides      : Date, Ride name, Route, Distance (km), Difficulty, Fee (Rs), Includes, Show on website

PAYMENT RECEIVED (Yes / No)
- New paid registrations get "No". After you receive the money and the screenshot on WhatsApp, change it to "Yes" (dropdown). Free ones get "N/A".
- Payment screenshots are NOT uploaded to the website or the sheet. The rider sends the screenshot in the WhatsApp chat.

RIDER DIRECTORY ON THE WEBSITE (Riders tab)
- The site shows up to 10 riders whose "Show on website" cell is Yes. New riders get "No" by default, so nobody appears until you change it.
- Search (name, profession, bike, bike number or phone digits) looks only among riders marked Yes and shows up to 10 matches.
- Only these fields go public: name, profession, bike model, bike number and WhatsApp number (Call / WhatsApp buttons).
  Email, birth date, payment and membership details are never sent to the website.
- Mark Yes only for riders who agreed to show their contact on the site.

UPCOMING RIDES TAB
- One row per ride. Fee (Rs) = charge per rider (breakfast / lunch). Write 0 for a free ride. If the Fee cell is EMPTY the site shows "Fee: to be confirmed".
- Includes = text on the card, e.g. "Breakfast + Lunch". Write "No" in Show on website to hide a ride. Past rides hide automatically.
- If every ride shows "Free ride" or "to be confirmed", the Fee column is empty or the script was not deployed as a New version.

IF SOMETHING LOOKS WRONG
- <Web app URL>?a=debug shows the tab names, the tab used for rides and riders, headings and counts.
- Press Ctrl+F5 on the website after any change. The browser console (F12) prints which tab rides were loaded from.

PRIVACY
Keep the sheet private (it holds phone numbers, emails and birth dates). Collect details only with consent.
