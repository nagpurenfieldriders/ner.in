NAGPUR ENFIELD RIDERS - WEBSITE (Zero Mile design)
==================================================
Open index.html in a browser, or upload this whole folder to any web host.

FOLDERS
  index.html     main page
  css/           style.css (design), fonts.css (font loading)
  js/main.js     rides, riders directory, join form, orders, engine sound
  images/        logo.jpg (your group logo). Add your own ride photos here
  fonts/         bundled fonts, SIL Open Font License (free for commercial use); licences in fonts/licenses

HOW IT WORKS
  Join form  -> opens WhatsApp to +91 90282 67858 with name, number, profession, bike, bike number, membership.
  Ride form  -> "Register for ride" on each upcoming ride opens WhatsApp with ride, rider name, number, bike, bike number and rider count.
  Order form -> opens WhatsApp to the same number with item, quantity, size, rider name and number.
  Admin number: change the WA value at the top of js/main.js.
  Memberships: Rider (Rs 0/-) and Royal Legend (Rs 1,200/- yearly). Payment is collected by the admin; there is no online payment.
  Engine sound: synthesized in the browser (no audio files, no recordings). Press "Start the engine", then hold "Hold to rev".
  Directory: edit the R list in js/main.js. The number plate shows each rider's real bike number.
